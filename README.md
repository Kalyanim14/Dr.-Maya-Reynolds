# Kalyani Mantramurthi Portfolio

A Next.js portfolio for Kalyani Mantramurthi, a full-stack software engineer specializing in Java, Spring Boot, React, Next.js, and AI-integrated applications.

## Highlights

- Responsive single-page portfolio with experience, skills, education, certificates, and contact details.
- Dedicated case-study pages for Orbit-DS, PersistAI, and the Food Delivery App.
- Orbit-DS includes a local screenshot captured from the deployed Storybook documentation.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```
